# Maki · 个人网站

这是一个以电影感视觉为方向的个人网站样稿。主页为分类目录；旅游页按城市归档，点选城市后通过“景色 / 美食”两个页签查看景点与城市味道。

上线与日常更新流程见 [DEPLOY.md](./DEPLOY.md)。

## 本地预览

直接打开 `index.html`，或在项目目录启动一个本地静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 文件结构

- `index.html`：主页、Maki 的个人介绍与分类目录
- `food.html`：旧美食链接的跳转页，现自动进入旅游页
- `travel.html`：竖排城市目录，点选城市后切换景点与美食
- `recommendations.html`：网页、文章、工具与推文收藏清单
- `styles.css`：视觉样式、响应式布局与动效
- `script.js`：分类渲染、城市选择、景色/美食页签、菜单与景色故事弹窗
- `assets/images/`：实拍旅行照片、头像与少量演示图片
- `previews/`：桌面端与移动端效果截图

## 后续替换

页面中的姓名、个人介绍、目的地、旅行故事、统计数字、邮箱和社交链接均为示例内容。替换照片时，建议保留横图 `16:10` 左右、竖图 `3:4` 左右的构图，以获得更稳定的版式效果。

- 主页分类：`旅游`、`推荐`
- 旅游记录：从主页分类或顶部导航进入 `travel.html`
- 旅行结构：`目的地 → 景点 / 城市美食`，目的地内容由 `content.js` 中的 `travel.destinations` 渲染
- 推荐清单：从主页分类或顶部导航进入 `recommendations.html`

## 城市与景点结构

目的地支持两种写法：

- 单景点：使用 `scenery` + `food`，适合以一个地点为主的目的地；当前四座城市均使用下面的城市写法。
- 城市：使用 `spots` 数组 + 城市级 `food`，适合柳州、济南、苏州、南京这类包含多个景点的城市。

目的地可以配置 `heroImage`，作为右侧目的地大卡片的虚化氛围背景；未配置时沿用原来的深色卡片。

`spots` 中的每个景点只需要 `scenery`。没有对应美食的景点可以加 `foodNote: "只记景色"`，页面会在景点卡片上标注；城市级 `food.items` 是所有景点共享的味道清单，可以用 `near` 标注“近趵突泉”等位置信息。城市没有 `food.items` 时，美食页签会自动隐藏。

景点可以在 `scenery.gallery` 中配置相册：数组每一项包含 `image`、`alt`，以及可选的 `thumb` 和 `caption`。`scenery.image` 用作卡片封面，点开卡片后会显示可左右切换的轮播与缩略图；`thumb` 建议使用小尺寸图片，避免缩略图加载原图。没有 `gallery` 的景点仍然打开单张景色笔记。

城市美食项也支持 `gallery`。配置两张以上照片后，美食卡片会出现相册入口，点开后复用同一套轮播弹窗。
